# CampRoguelite

Social roguelite with a 2000s summer camp theme.

Game engine is Godot. Developed mobile-first,
in terms of both target device and development device!

## Ideas

Overworld more like Mario world than most dating sims

Music adds drums during action

Responses keep conversations going and increase social rating, you have a response wheel and response windows are timed. You can learn responses for your wheel. Learning responses is timed also, and if your wheel is full you forget something if you try to learn it
